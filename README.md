# Jarvis AI

A cinematic, Jarvis-inspired assistant with a polished AI console, system awareness, and a witty British personality.

## Quick start

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

## Notes

This is a cinematic prototype inspired by Iron Man. It is designed for expansion with voice, command execution, and deeper integrations.
